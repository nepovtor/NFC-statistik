# NFC Statistics App

Короткая витринная версия проекта.

## Проект в одной фразе

Я сделал self-hosted веб-приложение для NFC-меток: оно открывает нужную ссылку по коду метки, считает переходы и даёт админку и клиентские кабинеты для управления NFC.

## Задача

Обычная NFC-метка сама по себе не даёт нормального управления:

- ссылку неудобно менять
- статистику переходов не видно
- клиент не может сам смотреть свои данные

Нужно было сделать сервис, который решает это централизованно.

## Решение

Я построил приложение, где каждая метка работает через короткий маршрут вида:

`/go/{tag_code}`

Дальше система:

1. находит целевую ссылку
2. записывает визит
3. делает редирект

Всё управление вынесено в веб-интерфейс.

## Что умеет продукт

- создавать NFC-метки и привязывать к ним ссылки
- считать переходы по каждой метке
- хранить журнал визитов
- выдавать доступ клиентам только к их NFC
- позволять клиенту самому редактировать свои метки
- экспортировать статистику в CSV
- работать локально, через Docker и в production
- закрывать админку через Tailscale

## Что здесь интересно технически

- FastAPI-приложение с разделением на роутеры, сервисный слой и шаблоны
- SQLite для быстрого self-hosted сценария
- серверные сессии, CSRF-защита форм и безопасные cookie
- клиентские кабинеты с разграничением доступа
- real client IP за reverse proxy и технические `/healthz` + `/readyz`
- отдельный bootstrap/migrate-step для схемы БД
- отдельный production-стек с Docker Compose и reverse proxy
- приватная админка через Tailscale
- автоматизация стабильной локальной работы на Mac через watchdog и launchd

## Для кого это подходит

- заведения с NFC-меню
- мастера и маленькие бизнесы
- мероприятия и стенды
- NFC-визитки
- продавцы NFC, которые хотят выдавать клиенту личный кабинет

## Как это можно описать клиенту

`Это сервис для NFC-меток: по касанию открывается нужная ссылка, а владелец видит статистику и управляет своими метками через кабинет.`

## Как это можно описать в резюме

`Разработал self-hosted FastAPI-приложение для управления NFC-метками: редиректы, статистика переходов, клиентские кабинеты, CSV-экспорт, Docker-развёртывание и приватная админка через Tailscale.`

## Как это можно описать на собеседовании

`Я сделал продуктовый сервис вокруг NFC-меток. Не просто редирект, а полноценную систему с админкой, кабинетами клиентов, аналитикой, экспортом и несколькими сценариями деплоя — от локального Mac-режима до production с доменом и reverse proxy.`

## Ключевая идея

Проект превращает обычную NFC-метку в управляемый цифровой канал:

- ссылку можно менять без перепрошивки логики приложения
- статистика собирается автоматически
- клиент может работать со своими NFC сам
- всё это можно держать у себя, без стороннего SaaS
